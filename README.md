# 我丢

把脑子里悬着的那件事，交给它管着。

> 一个给丢三落四的人做的轻量疗愈工具。它有一只叫「丢丢」的萌幽灵猫，从头到尾陪着你。

## 在线体验

- 网页版：见 GitHub Pages 链接
- PWA：用 Chrome / Safari 打开后，"添加到主屏幕"

## 功能

- **丢了** — 情感分级 → 寻物 / 翻篇 / 疗愈三条路径
- **还在** — 「先记着」+「寻找中」合并管理悬而未决的事
- **星图** — 已结案的物件以星空 / 时间轴两种视图查看
- **赛博上香** — 长按 3 秒点火 + 烟雾上升 + 钟磬，告别仪式
- **寻物卡** — Canvas 生成的暖心寻物卡，带丢丢 + 可选照片，一键分享
- **下一段旅程** — AI 织一段奇幻小故事，描写物件离开后的新生活
- **背景音乐** — 三种合成的环境音乐（温暖 F 大调 / 月光 D 多利亚 / 海风 A 五声），自带音量滑块
- **关于我丢** — 蔡格尼克效应理念页

## 技术栈

- 纯 HTML / CSS / 原生 JS，无构建
- Canvas 2D（寻物卡）
- Web Audio API（音效 + 背景音乐合成）
- Vibration API（触感反馈）
- Service Worker（PWA 离线 + 推送）
- localStorage（数据本地化）
- pollinations.ai（AI 文本 / 插图，匿名 API）

## 本地预览

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765/index.html
```

## 设计

详见 `我丢_PRD_v6.docx`（产品需求文档）。

整体调性：「暗夜柔糖」—— 深靛蓝底 + 玻璃磨砂卡片 + 半透明发光萌幽灵猫。

字体：得意黑（标题）+ LXGW 文楷（正文）+ JetBrains Mono（时间）。

## 开发笔记

- 数据全部本地存储（`localStorage`），换设备不同步
- AI 配图依赖 [pollinations.ai](https://pollinations.ai)（免费、不稳，超时回退到本地 SVG 兜底）
- 通知 / 振动 / 音乐都需要用户首次手势触发
